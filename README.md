# Rudraksh Tuwani

The homepage is in `index.html`. Add article links to `blog/index.html` in newest-first order. The homepage displays the first three links from that list. Each article can still be built and deployed from its project repo.

GitHub Pages publishes the root of `main`. To preview it locally, run `python3 -m http.server 8000` and open [localhost](http://localhost:8000).

To enable opt-in Google Analytics, set the public GA4 measurement ID in `assets/analytics.js`. Use the same web stream and cross-domain measurement for any Render articles you want included. To track Google Search performance, add a URL-prefix property for `https://rudrakshtuwani.github.io/`, verify it in Search Console, and submit `/sitemap.xml`.
